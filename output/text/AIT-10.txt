Coverage Summary:
Covers guided validation (open first missing field, sequential guidance, automatic execution after pass), prevention of availability search until validations succeed, validation categories (airports, dates, passenger rules, promo codes, journey type rules), visibility of Search button, loading indicator behavior, result content requirements, and end states for no availability and service failure. Includes positive, negative, and boundary scenarios while flagging key missing business rules needed for complete validation coverage.

=== Test Cases ===

[AIT-10-TC-001] Search button remains visible throughout the search journey (positive, priority: high)
Acceptance Criteria: AC1
Objective: Ensure customers can always access Search and are not blocked by scrolling or guided validation interactions.
Preconditions:
  - Customer is on flight search page with search form and Search button present
Steps:
  1. Scroll the page to different sections (top, middle, bottom) if the page is scrollable.
  2. Expand/open any collapsible search inputs (e.g., airports/date picker/passenger selector/promo code).
  3. Trigger guided validation by clicking Search with missing data.
  4. Observe whether Search remains visible and accessible during these interactions.
Expected Outcome: Search button remains visible and accessible at all times, including during scrolling and while guided validation opens missing fields.

[AIT-10-TC-002] Guided validation opens the first missing mandatory field when Search is clicked (positive, priority: high)
Acceptance Criteria: AC1
Objective: Verify the system guides the customer to the first missing required input upon Search.
Preconditions:
  - Customer is on flight search page
  - At least two mandatory fields are missing
Steps:
  1. Leave multiple mandatory fields empty (e.g., origin and dates).
  2. Click Search.
  3. Observe which input is opened/focused first.
Expected Outcome: The first missing mandatory field (based on the product’s defined order) opens automatically when Search is clicked.

[AIT-10-TC-003] Guided validation continues sequentially until all mandatory fields are completed (positive, priority: high)
Acceptance Criteria: AC1
Objective: Ensure the customer is guided step-by-step through all missing required fields.
Preconditions:
  - Customer is on flight search page
  - Multiple mandatory fields are missing
Steps:
  1. Click Search with required fields missing.
  2. Complete the field that the system opens.
  3. Attempt to proceed (e.g., click Search again, or close the field if applicable).
  4. Repeat until all required fields are filled.
Expected Outcome: After each completion, the system guides the customer to the next missing mandatory field until all required information is provided.

[AIT-10-TC-004] Search executes automatically after all validations pass (no extra customer action required) (positive, priority: high)
Acceptance Criteria: AC1
Objective: Confirm that once all required information is completed and valid, the system automatically runs availability search.
Preconditions:
  - Customer is on flight search page
  - At least one required field is missing initially
Steps:
  1. Click Search.
  2. Follow the guided prompts to fill in all missing mandatory fields with valid values.
  3. Do not click Search again after the last missing field is completed (if the UI permits).
  4. Observe whether the availability search starts.
Expected Outcome: Once all validations pass, the system automatically starts the flight availability search.

[AIT-10-TC-005] Availability search is not executed if mandatory field(s) remain missing (negative, priority: high)
Acceptance Criteria: AC1
Objective: Ensure no availability call is made until required information is present.
Preconditions:

Steps:

  2. Click Search.
  3. Do not complete the opened missing field.
  4. Observe whether results load or a loading state starts.
Expected Outcome: No availability search is executed; instead, the system keeps the customer in guided completion of missing required fields.

[AIT-10-TC-014] Search results display all required flight option attributes (positive, priority: high)
Acceptance Criteria: AC1
